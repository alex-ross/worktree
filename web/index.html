A SMALL TOOL FOR THE EVERYDAY

A few commands.
A lot less friction.

Git worktrees let you work on multiple branches in separate directories. worktree makes creating and moving between them feel natural.

Read the full usage guide ↗
01

Create & jump in

$ worktree create fix-parser

Create a worktree and switch to it. Existing branch? It uses that.

02

Find & open

$ worktree

Pick your workspace, or go straight there with worktree open fix-parser.

03

Explore another approach

$ worktree fork fix-parser experiment

Fork into a new branch with your staged, unstaged, and untracked work carried along.

Install with Homebrew, enable your shell, and run worktree inside a Git project.

Works on macOS and Linux. Git is required.
Homebrew builds the current main branch from source.

Other installation options on GitHub ↗

01 Install with Homebrew

brew tap alex-ross/worktree https://github.com/alex-ross/worktree
brew trust --formula alex-ross/worktree/worktree
brew install --formula --HEAD alex-ross/worktree/worktree

02 Enable your shell

zsh — add to ~/.zshrc 
source "$(brew --prefix worktree)/share/worktree/init.zsh"
bash — add to ~/.bashrc or ~/.bash_profile 
source "$(brew --prefix worktree)/share/worktree/init.bash"

↳ Open a new terminal, enter a Git project, and run worktree.
